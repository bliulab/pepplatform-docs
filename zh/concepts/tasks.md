# 任务类型

PepPlatform 支持四类肽段建模任务，定义于 `pepplatform/web/capabilities.py`。任务分为**单序列任务**与**Pair 互作任务**两大类，决定了输入格式与可用的建模路线。

下表的任务名称与平台 API 返回、Web 端展示的标签一致；`--task_type` 标识符才是稳定契约，因此正文中也可能使用更短的任务简称。

标签含义取决于训练数据。预测标签或分数是模型输出，不是对肽段功能或结合的实验确认。

## 任务一览

| 任务 ID | 名称 | 输入类型 | 输入格式 | 典型用途 |
| --- | --- | --- | --- | --- |
| `pep_function` | 治疗性肽功能预测 | 单序列 | 一条肽段序列 | 预测肽段的功能类别 / 多标签功能注释 |
| `pep_protein_interaction` | 肽–蛋白相互作用预测 | Pair | 肽段序列 + 蛋白序列 | 预测肽段是否与某蛋白结合 |
| `pep_hlai` | 肽–HLA-I 配体呈递预测 | Pair | 肽段序列 + HLA-I 序列 | 预测肽段与 HLA-I 分子的结合 |
| `pep_hlaii` | 肽–HLA-II 配体呈递预测 | Pair | 肽段序列 + HLA-II 序列 | 预测肽段与 HLA-II 分子的结合 |

## 单序列任务

### pep_function — 治疗性肽功能预测

- **输入**：单条肽段氨基酸序列。
- **输出**：数据集定义的功能标签。多标签指标包括 macro-F1 与 `SAcc`（样本/Jaccard 准确率）；默认检查点目标为 macro-F1，标签名称和数量由数据集决定。
- **适用路线**：预训练模型路线与经典特征路线均可。

::: warning 评估指标
`SAcc` 是多标签肽段功能评估的样本/Jaccard 准确率，与 Balanced Accuracy 不是同一指标。训练与 Web 摘要中，`Balanced Accuracy` 应完整写出而非缩写为 `BAcc`；`Recall (Sensitivity)` 是二分类任务的单一指标标签，不应将 Recall 与 Sensitivity 显示为两个独立值。
:::

## Pair 互作任务

三个 Pair 任务均以**两条序列**为输入，建模两侧之间的相互作用。它们共享 [Pair 互作](./pair-interaction) 的工作流，但在语义辅助损失等细节上各有差异。

### pep_protein_interaction — 肽–蛋白相互作用预测

- **输入**：肽段序列 + 蛋白序列。
- **输出**：是否结合（二分类）。
- **说明**：最通用的 Pair 任务，两侧序列长度差异较大。

### pep_hlai — 肽–HLA-I 配体呈递预测

- **输入**：肽段序列 + HLA-I 序列。
- **输出**：是否结合（二分类）。
- **说明**：统一语义层与其他 Pair 任务一样，自动采用训练集正交互邻域 Jaccard，不引入 HLA-I 专用锚位规则。详见 [语义辅助损失](./semantic-loss)。

### pep_hlaii — 肽–HLA-II 配体呈递预测

- **输入**：肽段序列 + HLA-II 序列。
- **输出**：是否结合（二分类）。
- **说明**：请按所选数据格式准备 HLA-II 伙伴表示与序列视图。任务默认参数不代表已经验证生物学结合。

## 任务与路线的关系

| 任务 | 预训练路线 | 经典路线 | Pair 工作流 |
| --- | --- | --- | --- |
| `pep_function` | 支持 | 支持 | — |
| `pep_protein_interaction` | 支持（受路线约束） | 支持 | 支持 |
| `pep_hlai` | 支持（受路线约束） | 支持 | 支持 |
| `pep_hlaii` | 支持（受路线约束） | 支持 | 支持 |

::: tip 预训练 Pair 任务
对于预训练 Pair 任务，支持双流及受约束的逐残基单流，两侧表示、mask 和建模架构需满足实际校验。详见 [特征路线](./routes)。
:::
