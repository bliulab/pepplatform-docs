# 集成模型 {#model-ensembles}

集成向导位于 `/ensembles/new`，从至少两个符合条件的已注册模型创建集成实验；运行成功后可登记推理模型。它复用成员模型，不重新训练成员的表征或权重。

## 创建条件 {#eligibility}

成员必须属于同一任务、支持推理、由当前 Web runtime 管理，并保存当前格式的评估信息，能够核实特征仅在训练集上拟合。标签名称与顺序必须一致；多标签功能任务还要求与数据集标签列一致。验证输入身份需要匹配，不能把不同数据或标签顺序的模型直接混合。暂不支持嵌套集成。

## 方法与权重 {#methods-and-weights}

| 方法 | 含义与限制 |
| --- | --- |
| `probability_mean` | 对概率分数加权平均，成员输出必须在 `[0, 1]` 内 |
| `logit_mean` | 概率经裁剪、logit 变换后融合，再转回概率 |
| `rank_mean` | 在完整请求批次内按标签排序并融合；至少需要两行，结果依赖批次组成，不能当作逐样本独立概率 |

权重可以等权、手动指定，或在验证集选择。手动权重按成员顺序填写，必须为有限非负数且至少一个为正，平台会归一化。验证集权重搜索使用 `grid_step`，范围为 `0.01–0.5` 且必须整除 1。模型选择目标和决策阈值目标分别指定，参见[模型选择目标](../concepts/selection-objectives)。

## 操作流程 {#workflow}

1. 选择任务、数据集和至少两个成员。
2. 选择融合方法、权重来源与验证目标；默认不评估测试集。
3. 执行 Preflight，修正成员、标签或数据身份问题。
4. 确认创建，在普通实验详情中查看状态和结果。
5. 完成后到模型库推理；集成使用保存的成员快照，推理结果包含融合方法与批次信息。

`PEP_WEB_ENSEMBLES_ENABLED=0` 暂停新集成创建，已有历史及模型推理继续保留。创建实验计入账户实验配额。参见[集成 API](../api/ensembles)。
