# 模型管理与推理

> 浏览已训练模型库，重命名或删除模型，并对所选模型直接运行推理。

## 功能说明

模型管理页采用左右双栏布局。左侧为模型列表，带数量标识卡，每行模型以单选按钮选择，展示名称、路线摘要以及「可推理 / 仅指标」、数据集、指标、创建日期等标识卡。行内提供「编辑」（内联重命名）与「删除」操作。

右侧为当前选中模型的 `InferencePanel` 推理面板。若该模型不支持推理（`metrics only`），面板会禁用并给出原因说明；支持推理的模型则可直接输入序列进行预测。

模型库位于 `/models`，展示 Web 运行时中已登记且当前账户可见的模型记录。选择模型可查看推理面板，`?model=<id>` 在 URL 中保留选择。单独通过 CLI 生成的模型不会自动登记到此处。

## 界面区域

### 模型列表（左栏）

- **数量标识卡**：显示模型总数，便于掌握库规模。
- **单选行**：每行含单选按钮、模型名、路线摘要，以及标识卡：
  - 可推理 / 仅指标
  - 数据集
  - 指标
  - 创建日期
- **行内操作**：
  - **编辑**：切换为内联重命名表单，修改后保存。
  - **删除**：移除模型（会弹出确认框）。

列表按创建时间倒序排列，最新训练出的模型排在最前。

### 推理面板（右栏）

显示当前选中模型的 `InferencePanel`：

- **支持推理**：可输入待预测序列并运行推理，结果按任务类型呈现（如类别概率或结合预测）。
- **不支持推理**：面板禁用并提示原因（如 `metrics only`、训练中断或未保存推理权重）。

面板顶部还会展示模型所用的路线摘要与数据集，便于确认推理输入格式是否匹配。

推理时需注意：

- 输入序列格式应与模型训练时的数据集一致。
- Pair 任务的模型需同时提供两侧序列。
- 推理结果按任务类型呈现（类别概率或结合预测）。
- 依赖 PSSM/PSFM 的模型可能需要后端具备 BLAST+，并在推理时临时生成 profile。
- `sample_graph` Pair 模型需要训练产物中保留参考图特征，否则会显示为不可推理。

不支持推理的常见原因：

- 模型标记为 `metrics only`，未保存推理权重。
- 训练中断或失败，仅保留中间指标。
- 资源未就绪，无法加载推理后端，例如缺少 profile 生成产物、BLAST+ 或图参考特征。

## 常见操作

1. 在左侧列表点击单选按钮选择一个模型（选中状态会同步到 `?model=` 查询参数，便于分享或刷新后保持）。
2. 点击「编辑」将行切换为内联重命名表单，修改后保存。
3. 不再需要的模型点击「删除」（会弹出确认框）。
4. 在右侧推理面板输入待预测序列并运行；若面板禁用，说明该模型仅含指标、不可推理。
5. 通过路线摘要与标识卡判断模型来源与质量，再决定是否用于推理。
6. 想查看模型的来源实验，点击实验链接进入 [实验详情](./experiment-detail)。

::: tip 选中即持久化
选中的模型会写入地址栏 `?model=`，刷新页面或分享链接都能保持当前选中模型。
:::

::: warning 仅可推理模型支持推理
`metrics only` 的模型（如训练中断或未保存推理权重）无法在推理面板使用，面板会明确提示原因。
:::

::: tip 路线摘要辅助判断
每行的路线摘要显示了特征与预测器路线，结合数据集与指标标识卡可快速判断模型适用场景。
:::

::: warning 删除不可恢复
删除模型会移除其权重与相关记录，且无法撤销；若仍有对比或引用依赖该模型，建议先确认后再删除。
:::

## 流式推理、历史与集成

推理显示阶段进度，成功请求写入当前账户的历史，可查看、删除并导出 CSV。输入表可使用 CSV/TSV/TXT，字段要求见[数据格式](../datasets/format)。可推理的注册模型还可用于[新建集成](./ensembles)。应核对分数类型：原始 SVM margin 和依赖请求批次的 rank 融合并非校准概率。即使模型元数据标记可推理，依赖或完整性检查失败时仍会被就绪检查阻止。
