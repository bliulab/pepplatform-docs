# 实验创建向导

> 四步式向导配置并发起训练，支持推荐模式与自定义模式，并承接重跑/克隆流程。

## 功能说明

向导页面以四个步骤引导你完成实验配置：问题定义、特征表示、预测器、复核启动。顶部头部可在「推荐」与「自定义」模式间切换——推荐模式隐藏高级选项、只保留核心字段；自定义模式则展开分词器参数、优化、正则化、语义相似度与各类分类器超参数等高级面板。

向导也是 AI 工作台规划候选的人工确认边界。从实验规划页进入时，页面显示候选标题、理由和生成时的 Preflight 快照，任务与数据集保持锁定；步骤四会根据当前编辑后的配置运行实时 Preflight。只有用户点击「开始训练」后，候选动作才会被确认并进入实验队列。需要更换任务或数据集时，可先「转为普通实验」解除方案关联。

页面左侧为四个可点击的步骤卡片，已完成步骤可回跳，未到达的步骤被锁定。头部还会实时显示当前路线摘要字符串。向导同时承担重跑/克隆流程：从实验列表或详情进入时，眉标（eyebrow）会提示当前为克隆来源。

向导把复杂的实验配置拆解为渐进式步骤，降低出错概率：每步只暴露与当前阶段相关的字段，Preflight 在复核阶段实时校验整体合法性，确保提交前配置可执行。

## 界面区域

### 头部

眉标（克隆或规划候选确认时显示来源）、标题、推荐/自定义模式切换，以及实时路线摘要字符串。规划交接还会显示候选来源、Preflight 快照和「转为普通实验」入口。

### 步骤导航（左栏）

四张可点击步骤卡片，点击已完成步骤可回跳；未达步骤被锁定，需按顺序推进。

### 步骤一：问题

任务类型选择与数据集选择。选择数据集后才会解锁后续步骤，路线摘要也会随之更新。

### 步骤二：特征表示

特征提取路线（经典 / 预训练），以及分词器、编码器、特征变换等选择。不同路线下可选项会动态变化。

### 步骤三：预测器

根据任务类型动态展示条件控件：

- **单序列经典路线**：建模架构（按“序列架构 / 序列链图架构”分组）、训练模式、预测头或下游分类器。`index` 编码不会显示 GCN/GAT。
- **单序列预训练路线**：池化表示 + 分类器；自定义 ESM2 还可选择残基表示 + GCN/GAT，固定为 `end_to_end + MLP`。
- **Pair 任务额外**：pair 策略、交互层级/交互架构、预测器路线、Pair 图架构、融合模式。HGT 是类型化 peptide/partner 图选项；GCN、GAT、GraphSAGE、Graph Transformer 使用融合样本节点。

### 高级面板（仅自定义模式）

分词器参数、优化、正则化、语义相似度、各类分类器的逐项超参数。推荐模式下隐藏。

### 步骤四：复核

- **实验名称输入框**：按论文的“分词器-编码器/表征-预测器”格式自动同步（如 `ESM2-Embedding-MLP` 或 `ESM2-TokenEmbedding-GAT`），也可手动修改。
- **四张复核卡片**：每张带「编辑」链接跳回对应步骤。
- **Preflight 卡片**：显示针对当前配置的有效/需关注徽标、执行脚本、错误与警告；这是提交时的权威结果。

### 页脚

返回 / 下一步 / 复核 / 开始训练。开始训练在「已选数据集且 preflight 有效」前为禁用。

## 常见操作

1. 在步骤一选择任务与数据集，解锁后续步骤。
2. 依次完成特征表示与预测器配置；需要细调时切换到自定义模式展开高级面板。
3. 进入步骤四复核，实验名称会自动同步，可手动修改。
4. 查看 Preflight 卡片，确认执行脚本无误，处理阻止提交的错误并审阅警告。
5. 若 Preflight 提示需关注，点击对应复核卡片的「编辑」返回修改。
6. 点击「开始训练」提交，跳转到 [实验详情](./experiment-detail)。

### 确认规划候选

1. 在实验规划候选上点击「去实验页检查」。
2. 核对候选理由和生成时的 Preflight 快照；任务和数据集来自原计划，默认不可更换。
3. 调整模型与训练配置，查看步骤四实时 Preflight。
4. 确认无误后由你点击「开始训练」。提交时后端会再次校验配置、方案上下文与配额，并把实验关联回实验方案。

::: tip 推荐模式更省心
推荐模式屏蔽了大量高级旋钮，适合快速跑通；熟悉平台后再切到自定义模式做精细调参。
:::

::: warning 必须先选数据集
未选择数据集时后续步骤被锁定，「开始训练」按钮保持禁用。Preflight 会实时校验配置合法性。
:::

::: tip 克隆来源会标注
从「重跑」进入向导时，头部眉标会显示克隆来源，方便你确认当前修改的是哪份配置。
:::
