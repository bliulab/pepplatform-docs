# 实验对比

> 并排对比 2 个及以上实验的指标、曲线与配置差异，并支持导出 Markdown / JSON 报告。

排名和高亮只比较所选指标与划分上的已报告数值。比较模型时应对齐任务、标签、数据划分与评估协议，显示上的较高分数不代表普遍更优。

## 功能说明

对比页以 URL 查询参数 `?ids=...` 驱动选中的实验集合，可从 [实验列表](./experiments) 或 [排行榜](./leaderboard) 的「对比选中」进入，也可直接修改地址栏。页面把指标矩阵、训练曲线、分析曲线与配置差异并排呈现，便于横向评判。

顶部头部提供标题、返回链接、导出 Markdown / JSON 按钮以及指标卡（选中数、任务、数据集）。所选实验以表格形式列出，每行可单独移除；移除后通过 `router.replace` 更新查询参数，保持地址与视图同步。

对比页适合在多个候选实验间做最终抉择：指标矩阵定位最优得分，训练曲线判断收敛稳定性，配置差异找出关键参数改动，分析曲线评估分类性能。导出的报告可归档或分享给团队评审。

## 界面区域

### 头部

标题、返回链接、「导出 Markdown」「导出 JSON」按钮，以及指标卡（选中数、任务、数据集）。

### 实验集合表

每行一个实验：名称链接、状态、任务、数据集、路线摘要、完成日期、移除按钮。移除后地址栏即时更新。

### 指标矩阵

排序指标与排序划分两个选择器控制行列；最优单元格以翠绿色高亮，便于一眼定位最佳实验。矩阵按所选排序指标降序排列，最左侧通常为得分最高的实验。

### 训练曲线

可在 `val_f1` / `val_auc` / `train_loss` / `val_loss` 之间切换的曲线对比，观察收敛趋势与过拟合情况。各实验的曲线以不同颜色区分，图例对应实验名称。

### 分析曲线

划分选择器 + ROC / PR 曲线并排对比，评估不同实验的分类性能。

### 配置差异

差异表格，带「仅显示差异」复选框；发生变化的单元格以琥珀色高亮，快速定位参数改动。未勾选时展示全部配置项的并排对照，便于通览。

差异表覆盖从任务、数据集到特征路线、预测器、训练超参的全部配置维度，是判断两个实验「到底改了什么」的最直接工具。

导出报告说明：

- **Markdown**：适合粘贴到文档或评审记录中阅读。
- **JSON**：适合程序化处理或归档到外部系统。

两种格式均基于当前选中实验生成，移除实验后再导出会反映最新的对比集合。

## 常见操作

1. 从 [实验列表](./experiments) 勾选实验后点击「对比选中」进入本页。
2. 在指标矩阵顶部选择排序指标与划分，定位最优实验（高亮单元格）。
3. 切换训练曲线的指标项，比较收敛趋势与过拟合情况。
4. 在分析曲线选择划分后对比 ROC / PR。
5. 勾选「仅显示差异」，查看配置差异表中被改动的项（琥珀色高亮）。
6. 如需移除某实验，点击实验集合表中的「移除」按钮。
7. 点击「导出 Markdown」或「导出 JSON」下载对比报告，用于分享或归档。

::: tip 地址栏即状态
对比选中的实验完全由 `?ids=...` 决定。移除某实验会即时更新地址，可分享或收藏当前对比视图。
:::

::: warning 至少 2 个
对比页需要至少 2 个实验才能形成有效对比；移除至不足 2 个时页面会提示补充。
:::

::: tip 报告可导出
导出的 Markdown / JSON 报告包含指标矩阵与配置差异，适合在文档或评审中引用。
:::

::: tip 最优单元格高亮
指标矩阵中每个指标的最优值以翠绿色高亮，无需手动比对即可一眼识别表现最佳的实验。
:::
