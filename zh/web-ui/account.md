# 账户、AI 服务与认证

账户页面管理显示名、配额和外部 AI 服务；登录、注册、邮箱验证和密码重置分别使用独立页面。模型训练产物仍由模型库管理。

## 个人资料 `/account/profile`

显示名可编辑（最多 40 字符），邮箱、角色和验证状态只读；修改后保存，页面显示成功或错误反馈。配额面板展示账户使用情况。

右上角使用“账户 / Account”文字菜单，个人资料页支持修改昵称。

## AI 服务 `/account/ai-services`

配置当前账户的外部 AI Provider，供[研究问答和实验规划](./agent)及实验诊断使用。填写服务商、配置名称、Base URL、模型 ID 和 API Key；高级选项包含 JSON object、Reasoning 与输出 Token 设置。支持新增、编辑、测试、启停和删除，保存后只回显 Key 后四位，不回显完整密钥。

保存连接不等于供应商或模型必然可用，应通过“测试连接”核验。实际 AI 请求取决于服务商配置、网络与服务商侧限制；创建训练任务另行消耗平台实验配额。

## 登录与注册

| 路由 | 操作 |
| --- | --- |
| `/login` | 邮箱、密码登录；“记住邮箱”只保存邮箱，不保存密码 |
| `/register` | 提交邮箱与至少 8 字符的密码，随后验证邮箱 |
| `/verify-email` | 输入邮箱与 6 位验证码；可以重发验证码 |
| `/password-reset` | 先发送验证码，再提交邮箱、验证码与新密码 |

认证开启时，访客仍可预览部分工作台并编辑普通配置；查询个人资源、提交训练、推理和 AI 请求会引导登录。具体资源详情、账户和管理后台受权限保护。注册邮件与密码重置依赖 SMTP；本地 debug_code 行为与生产环境设置见[认证 API](../api/auth)及[配置参考](../config/environment)。

## 常见操作

1. 在资料页修改显示名并保存。
2. 在 AI 服务页接入 Provider、测试连接，再到工作台选择服务。
3. 注册后完成邮箱验证；忘记密码时走验证码重置流程。
4. 管理员从账户菜单进入[管理后台](./admin)，普通账户不显示该入口。

相关接口见[认证 API](../api/auth)和[AI Provider API](../api/ai)。
