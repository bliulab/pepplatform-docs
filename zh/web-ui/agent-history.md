# 实验方案与迭代规划

> 浏览历史实验方案与迭代规划，并对多轮规划发起下一轮。

## 功能说明

本页由两个路由组成：`/agent/plans` 用于浏览历史方案与迭代并按条件筛选分页；`/agent/campaigns/:id` 用于检视某个多轮迭代并发起下一轮。迭代详情页布局与之相近，但聚焦于各轮次的进展与复核。

方案历史页顶部为头部（标题、副标题、「新建方案」链接），其下是筛选行（任务、数据集、状态、每页条数）。页面分为「迭代」区与「方案」列表区：迭代卡片展示状态、任务、轮次进度、目标与「查看迭代」按钮；方案卡片展示状态、任务、模型、是否含复核、目标、数据集、动作数，以及查看/复用/删除等操作，末尾为分页控件。

迭代详情页顶部为头部（目标、数据集、轮次进度，以及历史与新建方案链接）。下方提供 Provider 选择与「包含数据集预览」开关，以及「创建下一轮」按钮——当不满足条件时按钮禁用并显示原因。再下是按轮次序号排列的轮次列表，每轮含轮号徽标、状态、模型、质量、目标、已创建实验数、是否含复核、查看方案链接，以及最新复核块（总结、最佳实验、建议、风险）。

两个页面共享一致的视觉风格，但侧重不同：方案历史页面向横向浏览与筛选，迭代详情页则面向单一迭代的纵向推进。结合使用可以既回顾过往方案，又持续推进多轮迭代优化。

## 界面区域

### 方案历史页 `/agent/plans`

- **头部**：标题、副标题、「新建方案」链接。
- **筛选行**：任务、数据集、状态、每页条数，条件变更后即时刷新列表。
- **迭代区**：迭代卡片（状态、任务、轮次进度、目标、「查看迭代」按钮）。轮次进度展示已完成轮数与最大轮数，便于判断迭代是否仍在进行。
- **方案列表**：方案卡片，每张含：
  - 状态、任务、模型、是否含复核、目标、数据集、动作数。
  - **查看方案**：回到 [实验规划](./agent) 查看该方案详情。
  - **复用方案**：以该方案为模板进入设计器新建。
  - **删除方案**：移除方案记录。
- **分页**：底部分页控件，按筛选行的每页条数控制。

迭代区与方案列表区各自独立呈现：迭代卡片帮助追踪多轮迭代的整体进展，方案卡片则面向单次生成的回顾与复用。

方案卡片的操作含义：

- **查看方案**：跳转到 [实验规划](./agent) 查看候选与执行情况。
- **复用方案**：以该方案为模板新建，保留原配置。
- **删除方案**：移除方案记录（会弹出确认框）。

### 迭代详情页 `/agent/campaigns/:id`

- **头部**：目标、数据集、轮次进度，「历史」与「新建方案」链接。
- **下一轮控制**：Provider 选择、「包含数据集预览」开关、「创建下一轮」按钮（受阻时禁用并说明原因）。
- **轮次列表**：按轮次序号排列，每轮含：
  - 轮号徽标、状态、模型、质量、目标。
  - 已创建实验数、含复核标识、查看方案链接。
  - **最新复核块**：总结、最佳实验、建议、风险，帮助判断是否继续推进下一轮。

迭代详情页与方案历史页布局相近，但聚焦于各轮次的纵向进展，而非横向浏览多个方案。

## 常见操作

1. 在方案历史页用筛选行按任务/数据集/状态缩小范围，调整每页条数。
2. 在迭代区点击「查看迭代」进入迭代详情页。
3. 在方案列表点击「查看方案」回到 [实验规划](./agent)，或「复用方案」以其为模板新建，或「删除方案」移除。
4. 在迭代详情页查看各轮进展与最新复核；当上一轮未完成、已达上限或仍需复核时，「创建下一轮」会禁用并给出原因。
5. 满足条件后选择 Provider、按需勾选数据集预览，点击「创建下一轮」——系统会失效相关缓存并导航到 `/agent/design?plan_id=` 开始新一轮。
6. 在轮次列表点击「查看方案」回到对应方案的 [实验规划](./agent) 视图。
7. 阅读每轮的最新复核块，结合建议与风险决定是否继续推进或调整目标。

::: tip 下一轮门槛
创建下一轮受三道门槛约束：未达最大轮数、上一轮已完成、上一轮已具备复核。任一不满足按钮都会禁用并提示原因。
:::

::: warning 创建轮次会失效缓存
发起下一轮会令该迭代相关的生成缓存失效，随后自动跳转到实验规划并以新方案 ID 开始。
:::

::: tip 复用方案快速迭代
「复用方案」会以历史方案为模板进入设计器，保留原配置便于在其基础上调整目标或参数。
:::

::: warning 删除方案需确认
删除方案会移除其记录与相关产物，操作前请确认无需复用；进行中的迭代建议先完成或中止再清理。
:::
