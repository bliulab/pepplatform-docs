# 首页与仪表盘

平台将公开介绍与工作概览放在不同入口：`/` 和 `/welcome` 显示落地页，`/dashboard` 显示仪表盘。登录不会把 `/` 变成仪表盘；关闭认证时也沿用这些路由。

## 公开介绍与访客预览

落地页介绍四类任务、建模流程与工作台入口。访客可以进入标为预览的仪表盘、数据集、实验向导、模型库、排行榜与 AI 工作台页面，浏览界面并填写普通配置。个人资源查询和上传、预检、训练、集成、推理、AI 请求仍需要登录。具体资源详情、账户与管理页面也受权限控制。

## 仪表盘

`/dashboard` 汇总当前账户的实验、模型与任务族活动，展示实验活动热图、运行状态、可复用模型和近期活动。它还提供“配置 → 训练 → 评估 → 推理”的入口；数据加载失败时可重试，空数据有对应提示，不展示虚构的实验结果。

“新建实验”会重置实验草稿并进入 `/experiments/new`。基于已有配置继续探索时，应从实验列表或详情选择“重跑”。模型入口连接到模型库；是否真正可推理以模型标记和就绪检查为准。

## 常见操作

1. 从公开首页进入工作台，到 `/dashboard` 查看自己的活动。
2. 选择数据集并进入[实验向导](./experiment-wizard)，检查实际路线与 Preflight。
3. 在[实验列表](./experiments)监控训练，在[实验详情](./experiment-detail)查看证据。
4. 在[模型管理](./models)推理，或创建[集成模型](./ensembles)。
