# AI 工作台

> 在同一 AI 工作台中，通过 Tab 切换实验规划与持久化研究问答。

## 功能说明

AI 工作台包含两个独立占满内容区的页面：`/agent/design` 为实验规划，`/agent/chat/:conversationId?` 为研究问答。顶部 Tab 可无刷新切换；从问答切到实验规划时，正在进行的流式回答会留在后台继续生成。离开整个工作台时则会中止请求并保存已生成部分。`/agent` 仅作为兼容路由保留，不代表工作台拥有自主执行权限。

实验规划页采用多栏布局。上下文栏用于设定生成参数：选择 Provider、任务、数据集，填写目标描述，多选基准实验，并可选择是否包含数据集预览。从单实验诊断进入时，还会附加完整诊断报告并自动把来源实验设为基准。

主结果区展示生成产物。顶部显示所用模型、token 用量与上下文摘要，并提供卡片/对比两种视图模式切换。实验规划只负责生成、比较和编辑候选，不直接创建实验；用户选择一个候选后会带着方案关联与配置进入实验向导，在查看最新 Preflight 后自行确认。已经从向导确认的实验仍会在规划页显示进度，页面每 4 秒自动轮询，并在报告就绪（`report_ready`）时自动触发 AI 复核。

AI 问答页采用主流对话工作台布局：左侧按时间分组展示历史并支持搜索、置顶、重命名、删除；主区展示 Markdown 回答与每条消息的模型快照；底部输入框支持真正的增量输出与停止生成。一个会话可以逐轮更换模型，完整文本历史继续共享。

「联网搜索」默认关闭，发送后恢复关闭。启用时会检查服务器级 Tavily 额度并尝试一次 Basic Search，消息可保留编号引用和来源卡片。缺少 Key 或额度条件不满足时，搜索可能不可用；搜索失败会记录状态，普通问答仍取决于所配置模型服务的请求能否成功。这里不保证外部服务可用性或计费结果。

## 界面区域

### 配置面板（左栏）

- **Provider 选择**：指定生成所用 LLM。
- **任务选择**与**数据集选择**：限定方案范围。
- **目标描述**：textarea，说明你希望优化的方向。
- **基准实验多选**：作为参照的已有实验。
- **包含数据集预览**：复选框，让 LLM 看到数据样本。
- **生成按钮**：提交生成请求。

### 结果面板（右栏）

- **头部**：模型、token 用量、上下文摘要，卡片/对比视图切换。
- **候选入口**：一次选择一个候选，进入实验向导检查。
- **执行进度**：展示已由向导确认的实验链接、进度条与状态计数。
### 复核摘要

方案生成完成后展示 AI 复核结果，包含：

- **总结文本**：对整批方案的概括评价。
- **最佳实验**：复核推荐的最优候选。
- **指标证据**：支撑结论的指标数据。
- **分析发现**：对方案设计的观察。
- **建议**：下一步可采取的行动。
- **风险**：需注意的潜在问题。
### 候选卡片

每张候选卡片包含：

- **徽标**：泳道、动作、状态、有效、风险等级。
- **标题与理由**：方案名称与 LLM 给出的设计依据。
- **去实验页检查**：将配置、计划动作关联和生成时的 Preflight 快照带入 [向导](./experiment-wizard)。
- **编辑配置**：内联 JSON 编辑，保存时重新校验候选；保存不会创建实验。

### 上下文清单

展示参与本次生成的上下文条目（如基准实验、数据集预览等），便于核对 LLM 据以生成方案的输入。

## 常见操作

1. 在左侧选择 Provider、任务与数据集，填写目标描述。
2. （可选）多选基准实验作为参照，勾选「包含数据集预览」让 LLM 看到数据样本。
3. 点击「生成」，用卡片/对比视图检查候选间差异。
4. 需要时点击「编辑配置」修改 JSON 并重新校验候选。
5. 在一个有效候选上点击「去实验页检查」。
6. 在 [实验向导](./experiment-wizard) 查看生成时快照与当前实时 Preflight，调整配置后由你确认「开始训练」。
7. 返回实验方案查看运行进度；报告就绪后查看复核摘要与下一步建议。

::: tip 自动轮询与复核
方案运行时页面每 4 秒拉取一次进度；当检测到 `report_ready` 会自动拉取 AI 复核结果，无需手动刷新。
:::

::: warning 实验必须由用户确认
规划候选和候选卡片上的有效状态都不会自动创建实验。实验向导中的实时 Preflight、权限和配额检查才是最终提交依据。
:::

::: tip 基准实验提升质量
提供基准实验与数据集预览能让 LLM 生成更贴合现状的候选方案，减少无效配置。
:::
