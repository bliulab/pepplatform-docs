# 数据集管理

> 上传自定义数据集并浏览数据集库，附带逐数据集的校验报告。

## 功能说明

数据集页面采用左右双栏布局：左侧用于上传新的 `.zip` 数据集，右侧用于浏览与管理数据集库。上传时需指定名称与任务类型，平台会按任务展示对应的格式协议卡片，引导你打包正确的目录结构。

右侧库面板以分页卡片形式呈现数据集（每页 4 张），每张卡片展示名称、任务、格式、来源与划分数量等关键信息，并提供「用于新实验」「查看/隐藏报告」「删除」等操作。展开报告后可看到样本总数、标签模式、状态徽标，以及各划分的样本数、长度摘要与预览表格。

数据集是训练的起点，页面同时覆盖上传与管理两条链路：左侧完成新数据的引入与校验，右侧负责浏览、复用与清理。报告中的预览表与长度摘要能帮助你在训练前发现标签错误或划分不均衡等问题。

上传 ZIP 内的标签与配对表可使用 `.tsv`（tab 分隔），也可与 CSV 混用；同目录同名 CSV 优先。平台保留原 TSV 并生成用于校验、报告和实验读取的 CSV。支持位置见 [TSV 格式说明](../datasets/format#web-上传中的-tsv)。

## 界面区域

### 上传面板（左栏）

- **名称输入**：为本次上传的数据集命名。
- **任务类型选择**：4 个选项（`pep_function` / `pep_protein_interaction` / `pep_hlaii` / `pep_hlai`）。
- **协议卡片**：根据所选任务类型展示对应的 ZIP 打包指南。
- **拖放区**：支持拖放或选择 `.zip` 文件。
- **上传按钮**：提交后系统校验结构并自动规范化。

### 库面板（右栏）

分页展示数据集卡片（每页 4 张）。每张卡片含：

- 名称 / 任务 / 格式 / 来源 / 划分数量等标识卡。
- **用于新实验**：以该数据集为输入，跳转进 [向导](./experiment-wizard)。
- **查看/隐藏报告**：展开内联校验报告。
- **删除**：仅对 `upload` 来源的数据集可用。

内置数据集与上传数据集混合展示，通过来源标识卡区分；翻页控件位于面板底部。

### 内联数据集报告

展开后显示：

- **样本总数**与**标签模式**。
- **状态徽标**：反映校验是否通过。
- **各划分卡片**（train/val/test）：样本数、长度摘要、预览表。

预览表展示若干样本行，帮助你直观确认数据格式与标签分布是否正确。

如报告列出问题，应查看具体说明后再用于训练。

## 常见操作

1. 在左侧选择任务类型，参考协议卡片准备 ZIP。
2. 将 `.zip` 拖入拖放区（或点击选择），填写名称后点击「上传」。
3. 上传成功后，右侧库面板顶部会出现成功卡片，点击即可带入向导发起新实验。
4. 在库中翻页查找目标数据集，点击「查看报告」校验划分与样本分布是否符合预期。
5. 报告中确认各划分样本数与长度摘要无误后，再用于训练。
6. 不再需要的上传数据集，点击「删除」移除。

::: warning 删除限制
删除受账户权限限制。仅 `source: upload` 的自定义数据集可删除，[内置数据集](../datasets/builtin) 不提供删除入口。若仍有实验引用该数据集，删除会被拒绝。
:::

::: tip HLA-II 需 seqs.fasta
`pep_hlaii` 任务要求每个划分都包含 `seqs.fasta`，且 `pairs.csv` 必须含 `peptide`、`pair_pseudo`、`label` 三列，详见 [数据格式规范](../datasets/format)。
:::

::: tip 自动解包
ZIP 内可将所有文件包裹在一个根目录中，系统会自动解包并定位真实数据根目录，无需手动拍平。
:::

::: tip 报告先行再训练
上传后先展开报告核对样本数与标签分布，避免因划分不均衡或格式错误浪费训练资源。
:::
