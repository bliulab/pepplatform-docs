# 实验详情

> 监控并检视单个实验：运行状态、指标、日志、评估曲线、表示诊断、性能摘要、推理与 AI 分析。

## 功能说明

实验详情页提供「概览」「AI 分析」和「可视化分析」三个标签。「概览」显示运行与评估信息；「AI 分析」提供当前实验的多会话诊断；「可视化分析」按需生成分层性能和标签模式热图。

当实验处于运行状态时，页面每 2 秒自动刷新一次进度与日志，无需手动操作。失败时会在状态区展示错误卡片；运行中可取消、可加入对比、可重跑、可打开模型库。实验进入终态后自动停止轮询。

详情页将监控、诊断与推理放在同一实验作用域中。AI 分析负责解释已有证据、提出研究方向和成功判据，不生成正式候选配置。用户可将整份诊断报告交给 [AI 实验规划](./agent)，由规划器生成可比较候选，再进入实验向导确认。

## 界面区域

### 头部面板

实验名称、状态徽标、数据集、指标卡。指标卡随任务类型与可用结果动态展示。

### 运行状态 + 模型就绪度

进度条、各 ML 阶段指示器；表示导出到传统分类器的路线会显示「表示学习 → 嵌入导出 → 分类器拟合 → 评估与归档」四阶段轨道。LightGBM 拟合期间还会显示输出编号、树迭代、CPU 线程数、阶段耗时和稳定后估算的剩余时间。失败时显示错误卡片。操作按钮：

- **取消**：中止运行中的实验。
- **加入对比**：加入对比集。
- **重跑**：克隆配置进入 [向导](./experiment-wizard)。
- **打开模型库**：前往 [模型管理](./models)。

### AI 分析工作台

- **会话历史**：为同一实验创建多个诊断会话，可搜索、重命名、置顶和删除。
- **首轮诊断报告**：首条问题生成结构化报告，包括摘要、证据、发现、建议与局限性。证据来源可跳回概览中的对应日志、分析产物、模型或推理区。
- **后续问答**：在报告基础上继续追问，回答以流式 Markdown 展示。
- **上下文抽屉**：查看本次分析使用的实验上下文范围、采集时间和上下文指纹，并可选择加入数据预览、推理摘要或扩展日志。
- **诊断交接**：点击「在 AI 工作台规划下一轮」会携带整份报告，并将当前实验自动设为规划基准；分析页不再直接进入实验向导。

运行中的实验可以生成标记为「临时」的报告；实验结束后生成最终报告。排队中的实验尚无足够证据，AI 分析不可用。分析仅使用平台内的实验上下文，不执行网页搜索。

### 指标 + 日志

按划分展示 `SplitMetricChart` 或总体 `MetricChart`，以及调参结果；日志以深色终端 `pre` 块呈现，便于排查问题。进度事件采用普通换行记录，不使用会在 Web 日志中堆叠的终端回车动画；完整原始日志仍会保留。

### 评估曲线

ROC / PR 曲线、混淆矩阵、阈值扫描、分数分布等图表，用于评估分类性能。

### 表示诊断

聚类摘要、2D / 3D 投影、特征重要性，帮助理解特征空间质量。投影图可直观观察不同类别在特征空间中的可分性。

### 可视化分析

从概览入口或顶部标签进入 `/experiments/:id/visualizations`，依次选择分析类型、数据划分及指标，再点击「生成分析」。页面一次只加载一张图，只有活动任务轮询状态；进入页面不会自动分析测试分数。

- **分层性能**：HLA-I 的 allele × 原始肽长、HLA-II 的完整 HLA 配对 × 原始肽长，以及 PPI 的蛋白序列分组 × 原始肽长。蛋白组使用序列摘要标识，不推断靶标名称。
- **逐标签指标**：多标签功能预测的 ACC、F1、ROC-AUC、AUPR。ACC 是逐标签二分类准确率，AUPR 使用 Average Precision。
- **标签模式**：真实共现、预测共现、共同漏报、共同误报，可切换计数与 Jaccard；共现不等于类别混淆。

阈值指标和预测事件使用已保存的验证集阈值，不重新拟合。缺少可靠样本关联证据时，分层分析不可用；仅有标签和分数的旧产物仍可支持逐标签分析。warm/cold 等命名测试集分别展示。测试图属于事后分析。

灰色单元格表示缺失、指标不可计算或默认隐藏的低样本分组（少于 20 个样本）；可显式显示小样本数值。点击单元格或数据表查看支持度与原因。大矩阵按 50 行／50 列分页；CSV 导出完整聚合结果，PNG 导出当前视图并附带来源 JSON。

首版只读取 Web 管理的已完成实验。分析缓存位于 Web runtime 的 `visualizations/`，不会修改模型、原始预测、阈值或 `analysis.json`，也不会接入或重跑论文历史实验。

### 性能摘要 + 推理

指标卡网格、配置快照详情，以及 `InferencePanel` 推理面板。

## 常见操作

1. 打开详情页后，运行中的实验会自动每 2 秒刷新，观察进度条与日志即可。
2. 需要中止时点击「取消」（会弹出确认框）。
3. 切换到「AI 分析」，选择 Provider，并使用建议问题或输入自己的诊断目标。
4. 阅读首轮结构化报告；通过证据来源链接返回「概览」核对原始信息。
5. 在同一会话继续追问，或从左侧历史创建另一条诊断思路。
6. 点击「在 AI 工作台规划下一轮」，检查附加的诊断上下文并生成候选；选定候选后再到向导核对 Preflight 并手动提交。
7. 实验完成后查看评估曲线与表示诊断，并在配置快照中核对实际参数。
8. 模型就绪后，在底部 `InferencePanel` 直接进行推理，或点击「打开模型库」前往 [模型管理](./models)。

::: tip 自动刷新
运行期间页面每 2 秒拉取一次最新状态与日志，实验进入终态后自动停止轮询，无需手动刷新。
:::

::: warning 推理需模型就绪
仅当模型标记为 `ready for inference` 时，底部推理面板才可用；`metrics only` 的模型只能查看指标。
:::

::: tip AI 建议不会直接执行
AI 分析只负责解释证据和提出研究方向。正式候选统一由 AI 工作台生成，并必须进入实验向导，由 Preflight 给出可执行性结果并由用户最终提交。
:::
