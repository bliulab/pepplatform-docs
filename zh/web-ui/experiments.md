# 实验列表

> 浏览全部实验、监控运行状态，并进行停止、重跑、删除或勾选对比等管理操作。

## 功能说明

实验列表页汇总你名下的所有实验。顶部头部面板显示标题、副标题与「新建实验」按钮，并以指标卡展示「总数」与「活跃中」数量，便于把握整体进度。

下方列表面板带工具栏：展示实验总数、已勾选对比数量，以及「对比选中」按钮（跳转 `/experiments/compare?ids=...`）。每行实验展示详情链接、状态徽标、任务/数据集/更新时间等元信息，以及一组操作按钮：对比勾选框、停止、重跑、打开详情、删除。

实验的状态会随训练进程实时更新：排队中的实验等待资源调度，运行中则可在详情页查看日志与进度；进入成功、失败或已取消等终态后，方可执行删除。你可以在此页快速中止异常实验、复用成功配置发起重跑，或勾选若干实验进入对比视图横向评判。

## 界面区域

### 头部面板

标题 + 副标题 +「新建实验」按钮，以及「总数」「活跃中」指标卡。点击「新建实验」进入 [向导](./experiment-wizard)。「活跃中」统计当前处于排队或运行状态的实验数量。

### 工具栏

显示实验总数、已选中对比数量。点击「对比选中」将所选实验 ID 拼入查询参数并跳转到 [实验对比](./experiment-compare)。未勾选任何实验时该按钮禁用。

### 实验行

每行包含：

- **详情链接 + 状态徽标**：点击进入 [实验详情](./experiment-detail)。状态包括排队、运行中、成功、失败、已取消等。
- **元信息网格**：任务、数据集、更新时间，便于快速辨认实验上下文。
- **对比勾选框**：加入对比集（最多 6 个）。
- **停止**：仅在 `queued` / `running` 状态可用，中止后实验转为已取消。
- **重跑**：克隆实验草稿进入 [向导](./experiment-wizard)，可在其基础上调整参数。
- **打开详情**：跳转详情页查看曲线、日志与诊断。
- **删除**：仅在终态（成功/失败/已取消）可用，删除后不可恢复。

状态徽标含义：

- **排队**：已提交，等待资源调度。
- **运行中**：训练进行，可在详情页查看实时日志。
- **成功**：正常结束，模型与指标已保存。
- **失败**：异常终止，详情页展示错误卡片。
- **已取消**：手动停止，可重跑恢复配置。

操作按钮的可用性随状态变化：停止仅对排队/运行中可用，删除仅对终态可用，重跑则任意状态均可克隆配置。

对比勾选会跨翻页保留，便于在不同页挑选实验后一次性发起对比。

## 常见操作

1. 在列表中按状态徽标定位需要关注的实验，点击行进入 [详情](./experiment-detail)。
2. 对正在排队或运行的实验，点击「停止」中止（会弹出确认框）。
3. 想基于某实验调整参数再训练，点击「重跑」克隆配置进入向导。
4. 勾选多个实验（最多 6 个）后点击「对比选中」，进入对比视图。
5. 对已结束的实验，点击「删除」移除（会弹出确认框）。
6. 点击头部「新建实验」从零开始配置一次训练。
7. 点击行内实验名或「打开详情」进入 [实验详情](./experiment-detail) 查看曲线与日志。

::: warning 对比上限
对比视图最多支持 6 个实验同时对比。超出后多余的勾选将被忽略。
:::

::: tip 状态徽标速查
排队（等待资源）、运行中（训练进行）、成功（正常结束）、失败（异常终止）、已取消（手动停止）。仅终态实验可删除，运行/排队中需先停止。
:::

::: tip 重跑即克隆
「重跑」不会改动原实验记录，而是把其配置复制到草稿并打开向导，你可在向导中修改任意参数后另起新实验。
:::

::: tip 删除仅限终态
只有处于成功、失败、已取消等终态的实验才能删除；运行中或排队中的实验需先停止。
:::
